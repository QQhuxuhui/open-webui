# Epic 1: 合规用户管理与内容标识增强

**Epic Goal**: 为Open WebUI添加完整的用户身份管理、内容合规标识和反馈系统，使平台符合中国市场监管要求，同时保持现有AI对话功能的完整性和性能。

**Integration Requirements**: 
- 必须保持现有聊天功能100%可用性
- 所有新功能必须与现有Flask/Next.js架构无缝集成
- 数据库变更必须支持现有用户平滑迁移
- 性能影响不超过现有响应时间的10%

## Story 1.1: 数据库架构扩展与用户模型增强

作为系统管理员，
我希望扩展现有用户数据模型以支持手机号、实名认证和合规跟踪，
以便为后续功能提供坚实的数据基础，同时保持现有用户数据完整性。

### Acceptance Criteria
1. 扩展用户表结构，添加phone_number、real_name_verified、created_at等字段
2. 创建用户协议同意记录表（user_consents）用于跟踪隐私和服务协议同意
3. 创建举报反馈表（content_reports）支持内容举报功能
4. 创建短信验证码表（sms_verifications）管理验证码生命周期
5. 所有现有用户数据保持不变，新字段设置合理默认值

### Integration Verification
- IV1: 现有登录功能完全正常，不受数据库变更影响
- IV2: 现有用户可以继续正常使用所有聊天和模型管理功能
