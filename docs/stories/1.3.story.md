## Story Statement

作为新用户，
我希望使用手机号码进行注册和登录，并同意隐私和服务协议，
以便快速安全地访问平台服务，符合本地化用户习惯。

## Acceptance Criteria

1. **手机号注册页面**
   - 创建手机号注册页面，包含手机号输入和短信验证码验证
   - 提供用户友好的表单验证和错误提示

2. **协议同意机制**
   - 实现隐私协议和服务协议勾选，记录用户同意时间和版本
   - 支持协议版本管理和历史跟踪

3. **手机号登录功能**
   - 手机号登录功能，支持验证码登录方式
   - 提供"记住我"功能和安全的会话管理

4. **认证系统集成**
   - 集成现有认证系统，保持session管理一致性
   - 支持多种登录方式并存（邮箱、用户名、手机号）

5. **用户档案创建**
   - 新用户注册后自动创建完整用户档案
   - 设置合理的默认值和用户偏好

### API Specifications

**手机号注册**:
```typescript
POST /api/auth/phone/register
{
  phone_number: string;
  verification_code: string;
  password?: string; // 可选密码
  agreements: {
    privacy_policy: { version: string; agreed: boolean };
    terms_of_service: { version: string; agreed: boolean };
  };
  user_info: {
    nickname?: string;
    preferred_language?: string;
  };
}
```

**手机号登录**:
```typescript
POST /api/auth/phone/login
{
  phone_number: string;
  verification_code: string;
  remember_me?: boolean;
}
```

**协议管理**:
```typescript
GET /api/auth/agreements
Response: {
  privacy_policy: { version: string; content: string; last_updated: Date };
  terms_of_service: { version: string; content: string; last_updated: Date };
}
```
