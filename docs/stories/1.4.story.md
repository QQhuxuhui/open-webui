## Story Statement

作为用户，
我希望所有AI生成的内容都有清晰的标识，
以便我能够区分AI生成内容和其他信息，确保信息透明度。

## Acceptance Criteria

1. **AI文本标识**
   - 在所有AI文本回复下方自动添加"内容由AI生成，仅供参考"标识
   - 标识样式与现有UI保持一致，不影响阅读体验

2. **AI媒体内容标识**
   - 为AI生成的图片和视频添加"内容由AI生成"水印（四角之一）
   - 水印透明度和位置不影响内容查看

3. **多语言支持**
   - 支持标识文本的多语言配置
   - 根据用户语言设置自动切换标识语言

4. **性能优化**
   - 标识添加过程不影响聊天响应速度
   - 异步处理媒体水印添加

5. **标识持久化**
   - 标识信息随消息一起存储和导出
   - 聊天历史中正确显示AI标识

### API Specifications

**消息创建时AI标识**:
```typescript
// 扩展现有消息创建，自动设置AI字段
{
  content: string;
  ai_generated: boolean; // 自动设置
  ai_model_info: {
    provider: string;
    model_id: string;
    version: string;
  };
  content_labels: {
    inappropriate: false;
    generated_content_notice: "内容由AI生成，仅供参考";
    watermark_applied: boolean;
  };
}
```

**多语言配置**:
```typescript
GET /api/config/ai-labels
Response: {
  labels: {
    zh: "内容由AI生成，仅供参考";
    en: "Content generated by AI, for reference only";
    ja: "AIによって生成されたコンテンツ、参考のみ";
  };
}
```
