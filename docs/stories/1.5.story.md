## Story Statement

作为用户，
我希望能够对AI生成的内容进行举报或反馈，
以便帮助改进平台内容质量和处理不当内容。

## Acceptance Criteria

1. **举报入口和界面**
   - 在AI生成内容附近提供举报/反馈按钮
   - 创建举报提交界面，支持详细描述和截图

2. **举报分类系统**
   - 实现举报分类（不当内容、错误信息、技术问题等）
   - 支持自定义分类和详细原因描述

3. **举报记录管理**
   - 实现举报记录管理，防止恶意举报
   - 用户可查看自己的举报历史和处理状态

4. **管理员处理后台**
   - 为管理员提供举报处理后台（基础版本）
   - 支持举报状态更新和处理记录

5. **反馈循环机制**
   - 向举报用户反馈处理结果
   - 收集处理统计数据用于改进

### API Specifications

**举报提交**:
```typescript
POST /api/reports/submit
{
  content_id: string;
  content_type: 'text' | 'image' | 'video' | 'audio';
  report_category: ReportCategory;
  report_reason: string;
  content_snapshot?: any;
  attachments?: File[];
}
```

**举报查询**:
```typescript
GET /api/reports/my-reports
Response: {
  reports: ContentReport[];
  total: number;
  pagination: PaginationInfo;
}
```
