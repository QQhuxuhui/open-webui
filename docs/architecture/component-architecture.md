# 组件架构

## 认证服务

**职责：** 管理用户注册、手机验证和认证流程，同时保持与现有Flask-Login会话的兼容性。

**关键接口：**
- `/auth/phone/register` - 基于手机的用户注册，带短信验证
- `/auth/phone/login` - 基于手机的认证，带验证码
- `/auth/phone/send-code` - 短信验证码生成和传递
- JWT令牌生成和验证用于API访问
- 与现有Flask-Login中间件的会话集成

**依赖：** 短信服务 (AWS SNS/腾讯云), 用户数据库, Redis缓存用于验证码

**技术栈：** Flask蓝图, Flask-Login扩展, JWT库, SQLAlchemy ORM, AWS SNS SDK

## 用户资料服务

**职责：** 全面的用户资料管理，包括个人信息、实名验证和同意跟踪。

**关键接口：**
- `/users/profile` - 资料CRUD操作（昵称、头像、手机号）
- `/users/verification/real-name` - 实名验证文档提交和状态跟踪
- 隐私和条款协议的用户同意管理
- 资料历史和审计跟踪维护

**依赖：** 文件存储服务 (S3), 用户数据库, 认证服务

**技术栈：** Flask蓝图, SQLAlchemy模型, AWS S3 SDK, 图像处理库

## 内容标识服务

**职责：** 实时AI内容识别和标识，具有文本、图像和视频内容的水印功能。

**关键接口：**
- AI生成检测的实时内容分析
- 带有"内容由AI生成，仅供参考"的自动文本标识
- 带有"内容由AI生成"的图像/视频水印
- 实时标识更新的WebSocket集成

**依赖：** 聊天服务, 媒体处理服务, WebSocket服务器

**技术栈：** Flask服务层, Socket.io用于实时更新, Sharp用于图像处理, FFmpeg用于视频处理

## 内容举报服务

**职责：** 用户生成的内容举报和反馈系统，带有分类和审核工作流程。

**关键接口：**
- `/content/reports` - 举报提交和检索
- 举报分类和状态管理
- 审核队列和管理员界面
- 举报分析和趋势分析

**依赖：** 用户数据库, 聊天服务, 通知系统

**技术栈：** Flask蓝图, SQLAlchemy模型, 后台任务处理 (Celery)

## 短信服务

**职责：** 多提供商短信传递，具有回退策略、速率限制和成本优化。

**关键接口：**
- 带有安全哈希的短信验证码生成
- 多提供商传递 (AWS SNS主要, 腾讯云回退)
- 速率限制和滥用防护
- 传递状态跟踪和重试逻辑

**依赖：** AWS SNS, 腾讯云短信, Redis用于速率限制

**技术栈：** Flask服务层, AWS SNS SDK, 腾讯云SDK, Redis, Celery用于异步处理
